# 3x Mobile · Android alpha

Нативное приложение на Kotlin / Jetpack Compose для управления **3x-ui 3.7.0**, подключения телефона через VLESS и первоначальной подготовки VPS. Работает напрямую с вашим сервером, без промежуточного облака.

**[Скачать последнюю версию](https://github.com/KabanProduct/APP_3x-ui/releases/latest)** · Для OnePlus 15 выбирайте `3x-mobile-arm64-v8a.apk`.

Обновления доступны во вкладке **«Версия»**. [Автоматический выпуск и ключ подписи](docs/releases.md).

[Результаты тестирования 0.2.0](docs/validation-0.2.0.md), включая установку обновления из GitHub поверх старой тестовой release-сборки с сохранением профиля.

## Возможности

- Несколько сохранённых панелей; HTTPS, логин/пароль, 2FA либо Bearer API-токен. CSRF и cookie привязаны к отдельной сессии панели.
- Состояние Xray, подключения и клиенты; создание клиента, лимиты, срок действия, включение/отключение и удаление. Расширенный JSON-редактор inbound сохраняет исходные поля.
- Выдача ссылки и QR-кода; сохранение VLESS-ссылки в VPN-профиль телефона.
- VPN через встроенный **AndroidLibXrayLite v26.11.9 / Xray-core 26.11.9**, Android VpnService и нативный TUN. IPv4/IPv6 и DNS направляются в туннель. Само приложение исключено из VPN, чтобы управление и транспорт Xray не зацикливались.
- Мастер **VLESS + REALITY + Vision**, **VLESS + XHTTP + REALITY**, **VLESS + XHTTP + TLS**. Проверка порта по данным панели, генерация идентификаторов/ключей, проверка пригодности REALITY target со стороны VPS.
- SSH-проверка через пароль или ключ с подтверждением host key; существующая панель не переустанавливается. Неполная диагностика, другие службы, занятые порты или неподдерживаемая ОС блокируют предложение чистой установки.
- Установка фиксированного релиза 3.7.0 с проверкой SHA-256 архива, SQLite, systemd и HTTPS. Пароль генерируется и сохраняется до изменений на сервере; предусмотрено восстановление после обрыва SSH.
- Секреты зашифрованы AES-GCM с ключом Android Keystore, исключены из резервных копий; окна приложения защищены от снимков экрана.

## Первый запуск

1. Установите APK **arm64-v8a** из GitHub Releases на OnePlus. Это подписанная alpha-сборка для установки вручную, не публикация в магазине. Если раньше ставили debug-версию, сначала сохраните данные доступа и VLESS-ссылки, затем удалите её: подписи различаются. Следующие release-обновления устанавливаются поверх с сохранением данных.
2. Откройте **Панель → Добавить сервер**. Введите полный адрес вида `https://host:port/secret-path/` и данные авторизации. Пароли вводятся в приложении, не в переписке.
3. Для самоподписанного сертификата введите SHA-256, сверенный через SSH. Обычные сертификаты проверяются системным хранилищем. Проверка имени хоста не отключается.
4. Выберите существующего клиента или создайте нового. Нажмите **Ссылки / QR → Сохранить для VPN**.
5. Во вкладке **VPN** нажмите **Подключить** и подтвердите системный запрос Android. Статус различает запущенный туннель и успешную проверку интернета через Xray.

Новый VPS: вкладка **VPS**, SSH-данные, проверка отпечатка хоста, диагностика, затем предложение установки. Поддерживаются Ubuntu 22+ и Debian 12+, root, systemd, x86_64 или arm64. Установщик не меняет firewall: TCP-порт панели и порт VPN должны быть разрешены отдельно. Сертификат новой панели самоподписанный, закрепляется через SSH и действует 365 дней; автоматическое продление пока не реализовано.

## Сборка

Окружение: JDK 17, Android SDK 35, Gradle 8.11.1. Gradle Wrapper включён. Бинарный AAR скачивается отдельно из официального релиза с проверкой SHA-256:

```powershell
python scripts/bootstrap.py
python scripts/fetch-native.py
# Установить platforms;android-35, build-tools;35.0.0 и platform-tools через sdkmanager.
./scripts/build.ps1
```

`build.ps1` использует локальные `.tools`, запускает unit-тесты, собирает APK и выполняет lint. Для Windows-пути с кириллицей временно отображает ту же папку на свободную букву диска и снимает отображение после сборки. Требуется право запускать сетевые загрузки зависимостей.

При установленном системном SDK/JDK: `./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug`. Задайте `ANDROID_HOME` или `sdk.dir` в `local.properties`.

Выходы: `app/build/outputs/apk/debug/app-arm64-v8a-debug.apk` и `app-x86_64-debug.apk`. Android-тесты: `./gradlew :app:connectedDebugAndroidTest` на эмуляторе/устройстве. Инструментальные тесты используют временные профили, запрашивают согласие VPN и проверяют Keystore, интерфейс, реальное ядро и TUN.

## Границы первой версии

- API реализован по исходникам тега **v3.7.0**, commit `f727d04f6522bb94a8fb52e8352fdcafb51c11e1`. Для других версий изменения заблокированы. Испытания на пользовательской панели и установка на реальный чистый VPS ещё нужны.
- Поддерживаются VLESS TCP/RAW и XHTTP с REALITY/TLS. WebSocket, gRPC, FinalMask, ECH, ML-DSA, нестандартный VLESS encryption и сложные XHTTP downloadSettings не поддерживаются; такие известные варианты отклоняются.
- Редактор лимитов меняет срок на заданное число дней от текущего момента; 0 дней сохраняет прежний срок. При создании 0 означает бессрочный доступ.
- Нет автоматической установки 3x-ui на сервер с посторонними службами, обновления/миграции панели и автоматического выпуска публичного сертификата. TLS-шаблон inbound требует готовых путей сертификата и ключа на сервере.
- Нет split tunneling по приложениям, автозапуска VPN после перезагрузки и специальной обработки энергосбережения OxygenOS. Переключение сетей, сон и восстановление после длительной потери сети требуют испытаний на OnePlus.
- Проверка через Xray использует `https://www.gstatic.com/generate_204`. Она не доказывает доступность всех сайтов и не заменяет испытания маршрутизации DNS/IPv6 в вашей сети. Гарантий обхода любых блокировок нет.
