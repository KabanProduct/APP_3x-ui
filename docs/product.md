# Требования и архитектура

## Согласованная цель

Android-приложение для OnePlus 15: управление 3x-ui 3.7.0, VPN на самом телефоне и подготовка нового VPS через SSH. Русский интерфейс. Прямое соединение с сервером без промежуточного облака.

## Области реализации

1. Панель: несколько серверов, авторизация, inbounds, клиенты, лимиты, сроки действия, статистика, ссылки и QR. Адаптер API под подтверждённую версию. Секретный base path сохраняется и не попадает в журнал. Не переносить предположения об API main на 3.7.0.
2. SSH: ключ либо пароль, проверка host key с подтверждением первого отпечатка. Диагностика ОС, архитектуры, прав, служб, контейнеров, файлов установки, портов, диска. Ошибки команд означают неизвестное состояние, а не отсутствие служб.
3. VPN: Android VpnService, foreground notification, системное согласие, AndroidLibXrayLite v26.11.9 с нативным TUN из Xray-core. Приложение исключено из собственного туннеля, чтобы транспортные и управляющие соединения не зацикливались. Отдельный tun2socks не используется. APK для arm64 и x86_64; нативные сегменты имеют выравнивание 16 КиБ.
4. Шаблоны: REALITY/Vision как начальный сценарий, XHTTP/REALITY и XHTTP/TLS как дополнительные после проверки совместимости. Генерация UUID/ключей, валидация портов, параметров REALITY, домена и сертификатов. Не обещать обход всех блокировок.

## Проверка VPS

- Найден 3x-ui, даже остановленный: предложить подключение к существующей панели и диагностику; не переустанавливать.
- Панель отсутствует, диагностика завершена, ОС поддерживается, есть права, конфликты и посторонние нагрузки не обнаружены: показать предложение установки.
- Панели нет, но есть другие приложения: показать найденные службы; автоматическую установку не предлагать как для пустого VPS. Отдельная совместная установка вне первого сценария.
- Неизвестное состояние: показать причину и повторную проверку. Никаких изменений автоматически.

Перед установкой показать версию, порты и изменения. Установщик привязан к проверенному релизу/коммиту; не исполнять изменяемый удалённый main через curl | bash. Контроль результата, обработка обрыва SSH и повторная диагностика перед повтором. Не удалять существующие данные. Системные службы сами по себе не означают, что сервер занят пользовательскими приложениями.

## Защита данных

HTTPS с проверкой сертификата; самоподписанный сертификат требует отдельного доверия, без глобального отключения проверки. Секреты шифруются ключом Android Keystore, исключаются из backup и журналов. Отдельные учётные данные для SSH, API и VPN. Приватный ключ REALITY не включается в клиентский экспорт. При смене сервера не переносить cookie/токен на другой origin.

## Критерии приёмки

- Сборка APK, установка и запуск на физическом OnePlus; сборка и unit-тесты в CI.
- Реальные CRUD-операции клиентов и inbounds на отдельном тестовом 3x-ui 3.7.0, проверка сохранности неизвестных полей и обработки истекшей сессии.
- Чистый VPS, существующая панель, Docker-установка, занятые порты, недостаток прав и обрыв SSH покрыты интеграционными сценариями.
- VPN передаёт TCP/UDP, DNS и ожидаемый IPv6-трафик; DNS/IPv6 не обходят выбранную политику туннеля. Проверены переподключение Wi-Fi/мобильная сеть, сон, отзыв разрешения и остановка сервиса.
- Статус «Подключено» показывается после проверки реального туннеля, а не только запуска сервиса. Проверка из сети пользователя обязательна для оценки обхода блокировок.

## Реализованный первый этап

Реализованы API 3.7.0 (CSRF/cookie и Bearer), CRUD клиентов и inbounds, шаблоны, экспорт ссылок/QR, Keystore-хранилище, SSH-проверка/установка и VPN-служба с нативным Xray. Собирается APK. Проверки на Android-эмуляторе включают реальные Keystore и Xray, системное согласие и создание/остановку TUN.

Установщик намеренно минимальный: Ubuntu/Debian + systemd, SQLite и самоподписанный HTTPS-сертификат с закреплением SHA-256 через SSH. Не изменяет firewall, не устанавливает fail2ban/PostgreSQL, не настраивает продление сертификата. Данные незавершённой установки сохраняются до изменения сервера; восстановление сертификата возможно через повторную SSH-проверку. Сервер с остатками установки не считается пустым.

Нужны испытания API на пользовательской панели, установки на отдельном чистом VPS и поведения сети/энергосбережения на OnePlus. Доступ к пользовательскому серверу в ходе разработки не запрашивался и изменения на нём не выполнялись. Пароли вводятся локально в приложении, не хранятся в репозитории и не передаются в переписке.
