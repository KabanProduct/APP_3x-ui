# Выпуск и обновления

Репозиторий: https://github.com/KabanProduct/APP_3x-ui

## Автоматический выпуск

1. Изменить код и увеличить **оба** `versionCode` и `versionName` в `app/build.gradle.kts`.
2. Добавить описание `docs/releases/<versionName>.md`.
3. Проверить изменения локально и отправить коммит в `main`.
4. GitHub Actions запускает unit-тесты, lint и debug-сборку. После успеха собирает release с постоянной подписью, проверяет подпись и выравнивание, создаёт тег и Release с двумя APK и SHA256SUMS.

Повторная отправка кода с уже опубликованной версией выполняет проверки, но не заменяет опубликованный APK. Публикация выполняется только из `main`; pull request не получает секретов подписи. Незавершённый draft после ошибки требует проверки перед повторным запуском.

## Ключ подписи

Постоянный ключ хранится локально в игнорируемой папке `.signing/`, резервная копия для CI — в GitHub Actions Secrets:

- `RELEASE_KEYSTORE_BASE64`
- `RELEASE_STORE_PASSWORD`
- `RELEASE_KEY_PASSWORD`

Владелец должен сохранить защищённую резервную копию **всей `.signing/`**, включая файл пароля, отдельно от компьютера. GitHub не позволяет прочитать секреты обратно. Нельзя пересоздавать ключ для очередного обновления. Не прикладывайте папку к issue, релизам или исходникам.

`python scripts/setup-signing.py --upload` создаёт ключ только при его отсутствии и загружает его в Secrets через авторизованный GitHub CLI. Этот вспомогательный скрипт рассчитан на локальный Windows toolchain `.tools`.

## Обновление телефона

Вкладка «Версия» проверяет последний опубликованный обычный GitHub Release, пропуская draft/prerelease. Автопроверка при запуске ограничена одним успешным запросом в сутки, ручная доступна всегда. APK загружается по нажатию. Проверяются репозиторий, HTTPS, архитектура, размер, SHA-256 из GitHub API, package ID, versionCode, versionName и совпадение подписи с установленным приложением. Затем открывается стандартный установщик Android. При необходимости пользователь один раз разрешает установку из 3x Mobile.

Приватные репозитории не поддерживаются; GitHub-токен в APK не встраивается. При недоступности GitHub приложение продолжает работать, повторить проверку можно позже. Загрузка выполняется пока жив процесс приложения; после его завершения загрузку нужно повторить. Загрузка обновлений самим приложением идёт напрямую, поскольку оно исключено из своего VPN.

Переход с прежней debug-сборки на первую release-сборку требует удаления debug-приложения. Сначала сохраните данные доступа и VLESS-ссылки: удаление стирает локальное хранилище. Обычные release-обновления с той же подписью данные сохраняют.
