Первая подписанная alpha-сборка 3x Mobile.

- Управление 3x-ui 3.7.0: серверы, подключения, клиенты, лимиты и ссылки.
- VPN на телефоне через встроенный Xray и VLESS.
- Быстрые шаблоны REALITY + Vision, XHTTP + REALITY, XHTTP + TLS.
- Диагностика VPS по SSH и предложение установки на чистый совместимый сервер.
- Вкладка «Версия»: проверка GitHub Releases, загрузка APK, проверка SHA-256, версии, package ID и подписи; установка через Android.

Для OnePlus 15 скачайте **3x-mobile-arm64-v8a.apk**. x86_64 предназначен для эмуляторов.

Если установлена прежняя debug-сборка, сохраните исходные данные доступа и VLESS-ссылки перед её удалением. Эта release-сборка использует постоянную подпись и не установится поверх debug. Последующие release-обновления сохраняют данные приложения.

Это alpha: реальная пользовательская панель, установка на чистый VPS, энергосбережение OxygenOS и смена сетей ещё требуют испытаний. Нет гарантии доступности всех сервисов у всех операторов.
