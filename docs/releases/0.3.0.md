Доработки мастера и создания клиентов.

- Публичный адрес в мастере автоматически берётся из адреса подключённой панели. Его можно изменить вручную.
- SNI и REALITY target заполняются согласованной парой из проверенных сервером вариантов. Добавлены выбор домена, случайный выбор и повторная проверка через API 3x-ui.
- Новая прокручиваемая форма VLESS-клиента: Flow, несколько входящих, UUID, ID подписки, лимиты трафика/IP/HWID, сроки, автопродление, сброс трафика и дополнительные поля.
- Ошибка создания отображается в форме без потери введённых данных. Окно закрывается после успешного ответа сервера.
- Импорт VPN-профилей поддерживает Flow `xtls-rprx-vision-udp443`.

Для OnePlus 15: **3x-mobile-arm64-v8a.apk**. Обновление доступно во вкладке **«Версия»** и устанавливается поверх release 0.2.0 с сохранением данных.

Версия остаётся alpha. Работа новой формы с пользовательской панелью и физическим OnePlus ещё требует проверки. Для отключённого клиента 3x-ui 3.7.0 требует отдельной команды после создания; приложение её отправляет и сообщает, если отключение не удалось.
