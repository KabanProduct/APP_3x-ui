Редактирование клиентов и настроек подключений.

- Полный редактор существующих VLESS-клиентов: Flow, UUID, привязанные входящие, лимиты, срок, подписка и дополнительные параметры.
- Неизменённые сроки, точные лимиты в байтах и дополнительные поля сохраняются. Добавлен режим «Сохранить текущий срок».
- Изменения привязок применяются отдельными запросами с обнаружением конфликтов и сообщением о частичном сохранении.
- Удаление клиента доступно отдельной видимой кнопкой в списке и в редакторе, с подтверждением прекращения доступа.
- Окно настроек подключения показывает загрузку, ошибки и повторный запрос. Большая JSON-конфигурация открывается в отдельном редакторе; текст сохраняется при ошибке записи.

Для OnePlus 15: **3x-mobile-arm64-v8a.apk**. Обновление через вкладку «Версия» устанавливается поверх предыдущей release-сборки с сохранением данных.

Alpha: работа с пользовательской панелью и физическим OnePlus ещё требует проверки. Полный редактор клиента предназначен для VLESS-привязок; удаление доступно для всех клиентов.
