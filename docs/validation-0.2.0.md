## Результаты

- 30 unit-тестов прошли локально и в GitHub Actions. Включены 7 тестов политики обновлений: числовое сравнение версий, исключение draft/prerelease, ограничение источника и архитектуры, требование SHA-256, ограничения размера, отклонение некорректных тегов.
- Android Lint: 0 ошибок, 12 предупреждений (версии зависимостей, проверяемый custom TrustManager и рекомендации KTX).
- 4 инструментальных теста прошли на Android 15 / API 35: Keystore, нативный Xray, все пять экранов, согласие VPN и жизненный цикл TUN.
- GitHub Actions самостоятельно собрал и подписал ARM64 и x86_64 APK, проверил подпись и выравнивание 16 КБ и опубликовал Release.
- Опубликованный ARM64 APK отдельно скачан и проверен локально: подпись совпадает с постоянным release-ключом; SHA-256 совпадает с GitHub API.

## Реальное обновление через приложение

На принадлежащем задаче эмуляторе установлена специальная локальная baseline-сборка (versionName 0.1.0, versionCode 1) с новым механизмом обновлений и постоянной release-подписью. Это тестовый артефакт, не прежняя пользовательская debug-сборка.

1. В baseline создан профиль `update-test-preserved`, сохранённый в зашифрованном хранилище.
2. Приложение обнаружило GitHub Release 0.2.0 и показало описание.
3. Кнопка загрузки скачала настоящий x86_64 APK из опубликованного Release; проверки размера, SHA-256, package ID, версии и подписи прошли.
4. Приложение открыло Android-настройку разрешения установки из этого источника.
5. После предоставления разрешения кнопка «Установить» открыла системное подтверждение обновления.
6. Android установил приложение **поверх**: versionCode 2, versionName 0.2.0. После открытия тестовый профиль остался доступен, что подтверждает сохранение данных и доступа к Android Keystore.
